# YÊU CẦU ĐẦU RA

## Phần 1: Phân tích

Theo em, cách lưu code của Nam còn có nhiều rủi ro:

- Nam xóa nhầm code rồi nhấn Ctrl + S nên phần code cũ bị mất.
- Nam lưu nhiều file như v1, final nên dễ bị nhầm khi chọn file để làm.
- Nếu máy tính bị hỏng thì code có thể mất hết vì chỉ lưu trong máy.
- Nam gửi file qua Zalo nên các thành viên trong nhóm có thể dùng nhầm phiên bản, làm ảnh hưởng đến công việc chung.

## Phần 2: Cách khắc phục

Em nghĩ Nam nên kết hợp lưu code trên máy tính và trên Cloud để an toàn hơn.

- Đầu tiên, Nam vẫn lưu code trên máy như bình thường.
- Tiếp theo, Nam dùng Google Drive hoặc OneDrive để lưu thêm bản dự phòng.
- Nam nên dùng Git để lưu lại những lần sửa code, tránh phải tạo quá nhiều file khác nhau.
- Khi lỡ xóa nhầm code, Nam mở Version History, chọn phiên bản trước đó rồi khôi phục lại.
- Cuối cùng, Nam cần kiểm tra xem file đã được đồng bộ lên Cloud chưa.
